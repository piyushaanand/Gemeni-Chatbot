# 🤖 Gemini Chatbot  
An AI-powered chatbot built using **Spring AI**, **Spring Boot**, and **React**, leveraging **Google’s Gemini API** for intelligent and context-aware conversations.

---

## ✅ Features  
- AI-driven chatbot using **Google Gemini API**  
- Real-time interactive chat interface  
- Backend powered by **Spring Boot & Spring AI**  
- Frontend built with **React.js**  
- Supports multiple conversation contexts  
- User-friendly and responsive UI  

---

## 🛠️ Tech Stack  
**Frontend:** React.js, Bootstrap 
**Backend:** Spring Boot, Spring AI  
**AI Model:** Google Gemini API
